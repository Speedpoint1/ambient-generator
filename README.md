# Ambient Mustergenerator

Ein interaktiver Ambient-Mustergenerator im Browser: Ein Partikelsystem auf einem HTML5-Canvas erzeugt fließende Farbspuren, die auf Maus- oder Touch-Bewegungen reagieren.

## Verwendung

`index.html` direkt im Browser öffnen — keine Installation, kein Build-Schritt nötig.

- **Maus bewegen / Finger ziehen** — erzeugt fließende Farbspuren
- **Klicken / Tippen** — löst eine Farbexplosion aus
- **Palette** — wählt das Farbschema (Aurora, Sunset, Ocean, Neon, Monochrom)
- **Dichte** — steuert, wie viele Partikel pro Bewegung erzeugt werden
- **Nachleuchten** — steuert, wie lange Spuren sichtbar bleiben
- **Löschen** — setzt die Leinwand zurück
- **PNG speichern** — exportiert den aktuellen Stand als Bilddatei
- Das Panel oben links lässt sich über das ☰-Symbol oben rechts ein-/ausblenden

## Kompatibilität

Läuft in jedem modernen Browser mit Canvas-2D-Unterstützung, inklusive Touch-Geräten.
